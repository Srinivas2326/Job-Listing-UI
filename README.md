## **📌 Project Overview**

This project is a responsive **Job Listing User Interface** built using **React**.  
It allows users to browse, search, filter, and sort job postings using static mock data.

The objective of this project is to demonstrate:
- Frontend fundamentals
- Clean component structure
- State management
- Filtering and sorting logic
- Basic UI/UX understanding


## **✨ Features Implemented**

### **✅ Core Requirements**
- Display job cards with:
  - Title
  - Company
  - Location
  - Job Type
- Search jobs by title
- Filter jobs by location
- Filter jobs by job type (Internship / Full-time)
- Responsive layout (mobile-friendly)

### **⭐ Bonus Features**
- Sort jobs alphabetically (A–Z)
- Highlight searched keyword in job title
- Clear Filters button
- Minimal light theme design
- Smooth hover effects


## **🛠 Tech Stack**

- React (Functional Components)
- JavaScript (ES6+)
- CSS (Flexbox & Grid for responsiveness)
- Static JSON mock data

## **🧠 Implementation Approach**

- Used React functional components for modular architecture.
- Managed application state using the `useState` hook.
- Implemented filtering using JavaScript array methods (`filter`, `includes`).
- Implemented sorting without mutating original data.
- Added UX enhancements such as hover effects and a clear filters option.
- Designed a minimal light theme for clean visual experience.


## **📌 Assumptions**

- Static mock data was used as required by the assignment.
- No backend or database integration was needed.
- The focus was on frontend logic and UI responsiveness.
